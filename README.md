# Operation Chimera Cascade

Asterion Dynamics is a hybrid-cloud enterprise using Okta, Microsoft 365, GitHub, AWS, Azure, GCP, Kubernetes, Windows, macOS, and Linux.

This repository is an intentionally difficult incident response challenge designed to force:
- phased investigation
- timeline normalization
- separation of linked vs unlinked activity
- distinguishing benign-looking suspicious activity from malicious abuse of valid credentials

Not all suspicious artifacts are part of the same intrusion.
